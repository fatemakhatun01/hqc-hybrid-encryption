# Experimental Results

This directory contains the outputs generated by the implemented HQC-based hybrid encryption experiments.

The experiments were executed using the HQC reference implementation on Ubuntu Linux.

## 1. `kem_flow_output.txt`

This file contains the output of the basic HQC-KEM correctness experiment.

The experiment verifies:

- HQC key generation
- Encapsulation
- Decapsulation
- Equality of the derived shared secrets

Expected result:

```text
SUCCESS: shared secrets match


The experiment confirms that both sides derive the same 32-byte shared secret.
2. modular_dem_output.txt

This file contains the output of the modular DEM experiment.

The construction uses the prime:
p = 4294967291

The plaintext and shared secret are processed as 32-bit blocks using modular arithmetic.

Encryption is defined as:
c_i = (m_i + ss_i) mod p

Decryption is defined as:
m_i = (c_i - ss_i) mod p

The result verifies that the recovered message is identical to the original message.

Expected result:
SUCCESS: modular decrypted message matches original message

3. double_kem_xor_output.txt

This file contains the output of the two-ciphertext XOR combination experiment.

Two independent HQC encapsulations are performed under the same public key:
(ct1, ss1)
(ct2, ss2)

The DEM values are constructed as:
d1 = m1 XOR ss1
d2 = m2 XOR ss2

The public combination is:
d_combined = d1 XOR d2

After decapsulation, the receiver computes:
d_combined XOR ss1 XOR ss2

which simplifies to:
m1 XOR m2

The implementation verifies that the recovered value matches the expected XOR of the two plaintext messages.

Expected result:
SUCCESS: recovered value matches m1 XOR m2

Notes
These outputs demonstrate correctness of the implemented experiments.

The message-level XOR operation is performed at the DEM layer. The internal HQC ciphertext components are not algebraically combined.

The current implementation is intended for research and educational purposes.
